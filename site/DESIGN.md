# CMB research website

New repository-owned research landing page; deployment target is GitHub Pages for cmb-anomaly-lab, explicitly selected by the author. No portfolio files are modified.

Editorial academic aesthetic using native HTML/CSS, not an imitation of a named component system. White paper, navy ink, blue links and restrained orange accents reflect the measured-map palette. Georgia headings and system UI text avoid remote font dependencies.

DESIGN_VARIANCE: 5. MOTION_INTENSITY: 1. VISUAL_DENSITY: 4. The measured map and notebook are the primary tasks. Motion is limited to optional smooth anchor scrolling, disabled for reduced motion. No autoplay or decorative motion.

Navigation: sky, notebook, findings, research library. The map toggle swaps two real-data renderings with clear captions and pressed-state semantics. Scientific caveats accompany findings. Download links point to this repository's own Pages artifacts; the original 2 GB dataset stays at NASA/IPAC IRSA and Colab execution uses Google's service.
